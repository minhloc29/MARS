# Classical Baselines for CVRP (LKH-3 and HGS)

Package này cung cấp hai solver cổ điển chất lượng cao để đối sánh với các mô hình Neural Combinatorial Optimization (MARS, POMO, SIL, ELG...):
1. **HGS (Hybrid Genetic Search)**: Tích hợp qua thư viện `pyvrp 0.14.0`.
2. **LKH-3**: Solver Lin-Kernighan-Helsgaun mở rộng cho CVRP, thực thi qua subprocess với file `baselines/lkh/LKH.exe`.

Chi tiết hướng dẫn cài đặt và câu lệnh chạy thực nghiệm vui lòng xem tại:
👉 **[`GUIDE_CLASSICAL_BASELINES.md`](../GUIDE_CLASSICAL_BASELINES.md)** ở thư mục gốc của repository.
